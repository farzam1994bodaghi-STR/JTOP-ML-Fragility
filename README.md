# JTOP-ML-Fragility
The code has been developed to learn from the available data while simultaneously incorporating the physical constraints and governing principles associated with the input and output parameters into the model-training process. The input parameters, such as the steel yield strength and deck equipment load, have physically meaningful ranges within which the model is expected to operate. Therefore, before further processing, the input data are constrained to their predefined valid ranges using a clipping function. This procedure prevents the model from being trained on physically unrealistic or invalid input values and consequently promotes more reasonable and reliable predictions. Similarly, the structural drift ratio, which is considered the model output, is physically expected to remain within a positive and relatively limited range, for example, between 0% and 20%. To enforce these physical constraints, a strong penalty is incorporated into the loss function for predictions that fall outside the prescribed output range. This penalty guides the model toward physically meaningful predictions during the training process and discourages the generation of unrealistic output values. The custom loss function combines the mean squared error (MSE) with a penalty term that computationally enforces the specified physical constraints. This approach represents a physics-informed machine learning strategy in which physical knowledge is incorporated into the learning process as a constraint rather than relying solely on the available data. Such an approach can be particularly beneficial when the available training data are limited or incomplete, as the incorporation of physical knowledge can improve the stability and generalization capability of the model.
Importing Required Libraries
The required Python libraries are first imported for data processing, construction of different machine learning models, model training and evaluation, visualization, and file management. These libraries provide the fundamental tools required for data preprocessing, implementation and training of machine learning algorithms, generation of plots, and management of input and output files.
Loading and Preprocessing the Input Data
The user then uploads the input (`X.txt`) and output (`Y.txt`) data files, and the corresponding datasets are loaded into the Python environment. The input dataset consists of **five physical parameters**, while the output dataset represents the **structural drift ratio**. The output data are converted into a two-dimensional array to ensure compatibility with the subsequent data-processing and machine-learning functions. At this stage, input values falling outside their predefined physical ranges are also corrected using the `np.clip` function. This operation constrains the input variables to physically meaningful ranges before they are supplied to the machine learning model, thereby helping ensure physically consistent model training.
